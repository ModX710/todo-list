# Todo List

เว็บ Todo List แบบมีสีสัน เพิ่มงาน เลือกหมวดหมู่ และติ๊กว่าเสร็จได้ พร้อมสตรีค คำคมประจำวัน และแถบความคืบหน้า

- หน้าเว็บเป็นไฟล์ `index.html` ไฟล์เดียว (HTML + CSS + JavaScript) ฝากไว้บน GitHub Pages
- ล็อกอินด้วยอีเมลและเก็บงานในฐานข้อมูล [Supabase](https://supabase.com) ใช้ได้ทุกเครื่อง
- แต่ละคนเห็นและแก้ได้เฉพาะงานของตัวเอง (Row Level Security ใน `schema.sql`)
